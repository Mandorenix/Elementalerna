# Token & Arbetsmetodik (React/TypeScript)
- **FILHANTERING (TILLÅTET):** Du får och SKA skapa, redigera och radera filer automatiskt med dina inbyggda verktyg. Fråga inte om lov.
- **TERMINALKOMMANDON (FÖRBJUDET):** Kör ALDRIG 
pm install, 
pm run dev, 
pm run build eller andra tunga kommandon själv. Detta slukar tokens och låser terminalen.
- **Ge instruktioner:** Skriv ut terminalkommandon i kodblock så användaren kan köra dem.
- **Vänta på feedback:** Skriv "Väntar på [OK] eller felmeddelande" efter varje kommando.
- **Minimal output:** Skriv INTE ut hela filer i chatten om du redigerar dem direkt. Skriv bara en kort sammanfattning av vad du ändrade.
